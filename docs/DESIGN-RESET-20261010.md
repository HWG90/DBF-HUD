Current implementation constraint: David rejected the separate Fancy segmentation feature and new render pathways. The approved artwork belongs under the existing HUD Texture setting, shader layers and decoration system. The replacement WorldGUI renderer is retired. Camera shake must be handled inside the existing projection/rendering modules. See HANDOFF.md for the current package and live-test state; prior segmented candidate acceptance is historical.

David wants to start fresh on the HUD's visual style and information layout, with new eyes. The vertical Simple HUD and current panel designs are set aside during this exploration, but remain available as a fallback if the new direction does not work out.

The current Simple layout and panel families remain preserved as usable fallback designs, references, and recovery assets. Earlier visual approvals remain evidence for those checkpoints; they do not establish approval for a new design. The separate Neo-Geo review candidate is also not an automatic replacement direction.

This decision concerns presentation. Weapon-state readers, ammo semantics, rendering infrastructure, fonts, placement/editor controls, profiles, and persistence remain useful foundations. This note does not remove runtime modules, alter installed files, or change saved settings.

The design pass explores a fresh visual language and information hierarchy on one representative weapon before expanding across the catalogue. Begin from the weapon's information needs instead of inheriting the existing Simple layout or common tall-panel template. David selected Open with variable background translucency; returning to the current design remains an option.

David has chosen primary weapons as the first scope. The initial Liberator study lives in `dist/primary-design-study-01/index.html` and compares Receiver, Open, and Dial concepts against the same illustrative sample state. He liked Receiver and Open; Dial felt unusual but was not rejected. These are flat studies, not runtime implementations or final artwork acceptance. Other primary mechanics need their own readout hierarchy within the selected direction.

Review should judge the complete presentation: what is read first, what can be omitted or shown conditionally, ammunition and reserve clarity, and the weapon-specific character of the artwork. Catalogue coverage and offline tests do not establish visual acceptance.

Reusing four corner projections for the full planar panel subsequently reduced the recorded draw CPU average from 1.956ms to 0.540ms; David confirmed it stays below 2.5ms and remains visible.
