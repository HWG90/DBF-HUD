## Uninstalled Senator cylinder

[Shot/refill sequence](../preview/senator-rotating-cylinder-proposal.png) and [animation](../preview/senator-cylinder-rotation-proposal.gif) depict six rear cartridge bases in a hexagonal housing. Each observed shot advances a count-driven display by 60 degrees clockwise, carrying empty chamber identity with it and bringing the next loaded round to the fixed bottom firing position. Native chamber index, actual rotation and interpolation timing are not verified. Multi-shot count jumps, refill, ownership change and invalid samples are checked. Speedloader/ejection timing remains unsupported.

The housing, hub and chamber positions rotate; shading is generated with native rectangle primitives. Exact equal-color run merging preserves raster pixels and reduces maximum undecorated command count from 3264 to 2304 (29.4%). The displayed Helldivers-decorated preview reaches 2332 commands. Stable raster geometry is cached. This is still a dense prototype: no live performance claim or deployment approval.

Run `python tests/validate_senator_cylinder.py` for 1944 font/scale/state native/world geometry checks. Run `python preview/senator_cylinder_preview.py` to render the sequence and illustrative GIF (requires Pillow, the repository font atlas and local LuaJIT DLL).
